# efude

The engine of [Efude](https://github.com/852wa/Efude), an open-source painting
and manga app for Windows: brush engine, tiled canvas with layers and filters,
pen input, GPU painting, file formats (`.efude`, PSD) and manga tools.

This crate re-exports the engine crates: `efude-core`, `efude-input`,
`efude-stroke`, `efude-brush`, `efude-canvas`, `efude-gpu`, `efude-io` and
`efude-comic`. The app itself is not published here; download it from the
[releases](https://github.com/852wa/Efude/releases).
